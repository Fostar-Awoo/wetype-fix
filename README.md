# 简介

该项目是一个简单的Xposed模块，修复了微信输入法的一些用户体验问题。

目前已完成：

- [x] 修复英文输入下大写取消延迟（表现为：单击大写键后短时间按下两个及以上不同按键，大写状态会来不及取消导致出现两个大写字母）

- [x] 在Termux内使英文联想与纠错失效防止干扰输入（v1.1.0：四层防护——onStartInput 早期环境判定 + 设置读取/请求层强制关闭 + 引擎会话 SessionConfig 改写 + 候选列表分发前过滤英文词候选，彻底解决英文候选词仍显示的问题）

- [x] 中文“拼音显示”动态回滚（v1.1.0：仅在 Termux 等特殊环境回滚为候选栏显示字码；其它应用内恢复用户原始设置——未开启则不执行任何操作，切换应用即时生效）
